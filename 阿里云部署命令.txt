LATIC 询价协作系统——阿里云 ECS 测试部署命令
================================================

目标：Alibaba Cloud Linux 3，公网 IP 101.37.17.111，测试地址：http://101.37.17.111:3210
以下命令全部在阿里云 SSH 终端执行，按顺序执行。密码只在 SSH 提示时输入，不要发送给他人。

一、阿里云安全组
------------------------------------------------
添加入方向 TCP 22（仅你的办公 IP）和 TCP 3210（测试时你的办公 IP或公司网段）。不要开放 TCP 3306。

二、更新系统
------------------------------------------------
sudo -v
sudo dnf upgrade-minimal --security -y
如果更新了内核：sudo reboot，重新 SSH 登录后继续。

三、安装 Node.js 20 和 Git
------------------------------------------------
sudo dnf install -y curl ca-certificates git tar gzip gcc-c++ make python3
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs
node -v
npm -v
git --version

四、安装 MySQL 8
------------------------------------------------
sudo dnf install -y https://dev.mysql.com/get/mysql84-community-release-el8-1.noarch.rpm
sudo dnf module disable mysql -y || true
sudo dnf install -y mysql-community-server
sudo systemctl enable --now mysqld
sudo systemctl status mysqld --no-pager
mysql --version
sudo grep 'temporary password' /var/log/mysqld.log
sudo mysql_secure_installation
按提示设置 root 密码并保存，不要把 root 密码发给我。

五、下载项目
------------------------------------------------
mkdir -p ~/apps
cd ~/apps
git clone -b agent/document-center https://github.com/HYtonmi0528/turbo-waddle.git latic-rfq
cd ~/apps/latic-rfq
npm ci --omit=dev
如果 GitHub 下载失败，可在本地下载压缩包后上传并解压到 ~/apps/latic-rfq。

六、初始化数据库
------------------------------------------------
cd ~/apps/latic-rfq
npm run server:init
按提示输入：MySQL地址直接回车（127.0.0.1）；端口直接回车（3306）；管理员账号 root；管理员密码输入刚才设置的 root 密码。
成功后应看到“数据库初始化完成”。
ls -l server-data/config.json
ls -l server-data/files
不要公开 server-data/config.json。

七、启动网页服务
------------------------------------------------
cd ~/apps/latic-rfq
npm run server
另开 SSH 窗口检查：
sudo ss -lntp | grep 3210
curl -I http://127.0.0.1:3210/
浏览器访问：http://101.37.17.111:3210
第一次选择“我是负责人，创建初始管理员”。npm run server 窗口不能关闭。

八、使用 PM2 后台运行
------------------------------------------------
前台测试成功后，在运行窗口按 Ctrl+C，然后执行：
cd ~/apps/latic-rfq
sudo npm install -g pm2
npm run pm2:start
pm2 status
pm2 logs latic-rfq --lines 50
pm2 save
pm2 startup systemd
pm2 startup 会打印一条 sudo env PATH=... 命令，请复制执行，再执行 pm2 save。
常用命令：pm2 restart latic-rfq；pm2 stop latic-rfq；pm2 logs latic-rfq。

九、测试清单
------------------------------------------------
浏览器可访问公网 IP；负责人可创建管理员；管理员可注册并启用员工；其他电脑可用同一公网地址访问；可上传下发询价表；员工可填写保存；管理员可导出；资料中心可看到文件；PM2 重启后数据仍存在。

十、故障排查
------------------------------------------------
pm2 status
pm2 logs latic-rfq --lines 100
sudo systemctl status mysqld --no-pager
sudo ss -lntp | grep -E '22|3210|3306'
curl -s http://127.0.0.1:3210/api/setup/status
网页打不开时确认安全组 TCP 3210，并执行：
sudo firewall-cmd --state || true
sudo firewall-cmd --permanent --add-port=3210/tcp
sudo firewall-cmd --reload
数据库失败时：mysql -u root -p -e "SELECT VERSION();"；sudo systemctl restart mysqld
不要删除 server-data，也不要删除 MySQL 数据目录。

十一、备份
------------------------------------------------
mkdir -p ~/backup/latic-rfq
tar -czf ~/backup/latic-rfq/files-$(date +%F).tar.gz ~/apps/latic-rfq/server-data/files
mysqldump -u root -p --single-transaction --routines --triggers latic_rfq > ~/backup/latic-rfq/latic_rfq-$(date +%F).sql

十二、后续正式化
------------------------------------------------
测试稳定后再配置域名、Nginx、HTTPS、RDS、OSS、自动备份和监控。正式环境不应直接暴露 3210 和 3306，网页应通过 HTTPS 443 反向代理访问。
